The phase instructions are a development convention. They are not terminal commands or a requirement for running the project. Historical machine paths in the progress log record where checks happened; use your own project folder for setup.

Files in `upstream/` preserve the original project's documentation and workflows. They describe the older EPUB pipeline and are not the Windows edition's operating instructions.
