# PDF review

Inspect the actual rendered PDF, not only the source HTML.

- Cover, title page and contents: hierarchy, no clipping, correct author/title, legible entries and matching page numbers.
- Every section boundary: correct order and heading kept with the opening content.
- First and last pages of long chapters: no lost endings, duplicate titles, accidental empty pages or isolated ornaments.
- Notes: reference and target agree, note markers stay with words, and notes use the reading column.
- Code, tables, quotations and images: retain content and indentation; check wrapping, spacing, font substitution and page breaks.
- Every audit warning or sparse page: decide whether it is a valid short ending or an awkward break needing repair. Do not lower type size to force a shorter book.
- Navigation: audit destinations and outline order; manually try links where a reader is available. Record which checks were automated.
- Export again with one changed setting. Confirm a different filename and unchanged first-file fingerprint.
- On the intended device: check reading size, a text highlight, handwriting in both spaces, contents/bookmarks and responsiveness. Record actual feedback; successful generation is not device approval.
